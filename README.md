# ISLEFORGE: Echoes of the Core — versión de prueba

Juego de acción estilo *Jackal* (NES) hecho en HTML. **Juega aquí:** https://students-zone-es.github.io/isleforge/

Se juega en el navegador del ordenador, con teclado y ratón:
- **WASD** moverse · **Ratón** apuntar · **Clic izquierdo / Espacio** disparar
- **Clic derecho / Shift** ataque en arco (pasa por encima de los muros) · **F** camuflaje
- **E** mini-dron · **T** torreta · **Q** escuadra · **R** evolucionar aliado · **X** pedir el Orbe Vital · **P / Esc** pausa

La partida se guarda en tu navegador. Es una versión en desarrollo: si encuentras fallos, avisa.
